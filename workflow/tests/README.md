# Workflow tests

## Historical profile fixture

The legacy `opencode` fixture in `TaskProfileTests.fsx` represents the built-in profile from source commit `d953f48` (`workflow/domain/Workflow.fs`). Its profile fingerprint is `a85923f9017bf758521a4a2e67338458399f3e0f6f0ffb0ed2165e0b1413b71b`.

The fingerprint was generated by loading the historical `Workflow.fs` with `dotnet fsi`, resolving its built-in `opencode` definition, and creating a task through that producer. The fixture retains its execution validation/review guards and `profileGuardKeys` provenance (`G1` → `validation`, `G2` → `review`).

## Running the suites

The Workflow behavior suites are standalone F# scripts. From the repository root, run each with `dotnet fsi --exec --quiet <script>`; they do not use `dotnet test`.

```powershell
$env:MCP_WORKFLOW_PACKAGED_DLL = (Resolve-Path "workflow/bin/Release/net11.0/Mcp.Workflow.dll").Path
$tests = @(
  "workflow/tests/WorkflowTests.fsx",
  "workflow/tests/EvidenceIdentifierV2Tests.fsx",
  "workflow/tests/TaskContractTests.fsx",
  "workflow/tests/TaskPathSafetyTests.fsx",
  "workflow/tests/TaskSupportingArtifactTests.fsx",
  "workflow/tests/TaskProfileTests.fsx",
  "workflow/tests/EphemeralLockInvariantTests.fsx",
  "workflow/tests/AuthorityMetadataTests.fsx",
  "workflow/tests/SchemaParityGuardTests.fsx",
  "workflow/tests/WorkflowMcpTests.fsx",
  "workflow/tests/WorkflowMcpNativeCompatTests.fsx",
  "workflow/tests/WorkflowMcpFindingTests.fsx",
  "workflow/tests/PackagedRuntimeCoordinationTests.fsx"
)
foreach ($test in $tests) {
  dotnet fsi --exec --quiet $test
  if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
}
```

The three `WorkflowMcp*` process-boundary scripts require an existing Release entry DLL. `PackagedRuntimeCoordinationTests.fsx` otherwise publishes the producer, so set `MCP_WORKFLOW_PACKAGED_DLL` to an already-authorized Release DLL when builds are out of scope. Unix FIFO/socket cases in `TaskSupportingArtifactTests.fsx` are explicitly skipped on Windows hosts.

`DistributionTests.fsx` invokes the release build and pin-generation scripts, which mutate distribution artifacts; run it only when release-artifact generation is authorized. `MutexAbandonmentHelper.fsx` is a child-process helper for `PackagedRuntimeCoordinationTests.fsx`, and `TaskCreate.fsx`, `TaskGet.fsx`, `TaskApply.fsx`, and `TaskValidate.fsx` are command entrypoints rather than standalone suites.
